# Context-informed discovery

Self-disclosed work/life context and named cultural interests enter a typed person context. New chat disclosures require exact user quotes. A role is a clue, not a preference; there is no profession-to-activity lookup table.

Qloo audiences come from its live professional, hobby, leisure and life-stage catalogs, cached for one day. Unsupported IDs are omitted. No audience match is valid: technology and medical audiences exist, but teacher and research-student equivalents were not present in the checked professional catalog. Political/religious audience IDs are excluded.

Named books, films, artists, podcasts, games, brands, destinations and places resolve with typed entity search. Only one exact-name, exact-type match becomes a signal. Ambiguous/absent matches remain visible as unused. Cultural entities are interest signals; the audience weight is 0.35, a relative provider weight, not a probability or measured accuracy. Discovery cache identity includes audiences and entity inputs.

The chat explains search inputs separately from venue-specific evidence. Context is saved for future outings only through an explicit remember action, and removable in the personal profile. Shared day/circle participants can see the shared profile.

Research guides reversible experience suggestions and contextual cards: recovery dimensions (https://doi.org/10.1037/1076-8998.12.3.204), leisure and need fulfillment (https://doi.org/10.1111/aphw.12196), and observational teacher diary research (https://pubmed.ncbi.nlm.nih.gov/11482632/). These sources do not prescribe preferences by occupation, prove causal wellbeing benefits, or support alcohol as a stress intervention. The planner assembles one outing; a weekly request must retain that horizon without claiming a seven-day itinerary exists.

Circle email delivery requires RESEND_API_KEY and a verified CIRCLE_INVITE_FROM sender in runtime configuration. Do not commit values. Invitations are recipient-bound, expiring and single-use; implemented code is not evidence of delivered mail.
